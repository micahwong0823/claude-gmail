# claude-gmail

A personal tool that lets Claude Code, running on my own computer, read and manage my own Gmail accounts through the Gmail API. It is not a public service and is used only by me.

## Privacy

This app is used only by its owner. Gmail data is accessed solely on the owner's own computer, at the owner's request, to read, label, draft and send the owner's own email. No data is collected, stored on any server, sold, or shared with third parties by this app. OAuth tokens are stored locally on the owner's computer and can be revoked at any time at https://myaccount.google.com/permissions
